Accessibility statement

Conformance status

{{ wxhub_brand_name }} aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.1, level AA, as required by EN 301 549 and the AgID accessibility guidelines. The service is partially conformant: the Hub pages, sign-in, gallery, and administration pages are designed to conform; the limitations below remain.

Measures in place

  • Skip link, landmark regions, a single page heading, and labelled navigation.
  • Text and controls meet a 4.5:1 contrast ratio in the day and night themes.
  • Visible focus indicators and full keyboard operation; no keyboard traps.
  • Form fields have programmatic labels; errors are announced and associated with fields.
  • Status is conveyed by text, not colour alone; reduced-motion and forced-colour preferences are respected.
  • Layouts reflow to 320 CSS pixels without horizontal scrolling on Hub pages.

Known limitations

  • JupyterLab and JupyterLite are third-party applications whose accessibility is evolving; some widgets and drag-and-drop interactions are hard to use with screen readers.
  • Charts and maps generated by notebooks are images without automatic text alternatives. The data behind each figure can be displayed as a table by running the corresponding cell with the data frame as output.
  • Notebook content written by users is outside the provider's control.

Feedback and enforcement

Report accessibility problems or request content in an accessible format {% if wxhub_privacy.accessibility_contact %}to {{ wxhub_privacy.accessibility_contact }}{% else %}through the University's official channels{% endif %}. If the answer is unsatisfactory, you may use the enforcement procedure of the Agency for Digital Italy (AgID) under Article 3-quinquies of Law 4/2004.

This statement is based on a self-assessment and is reviewed with each release.
